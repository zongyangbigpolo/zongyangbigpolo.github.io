Personal Projects

Selected projects I maintain on GitHub, covering remote desktops, cross-platform libraries, and AI applications. Each repository's README describes its current features and development status.

NebulaDesk | Cross-platform Remote Desktop

Built with Rust, Tauri, and QUIC for macOS, Windows, and Linux. Provides device management, access control, and standalone native remote session windows with end-to-end encrypted transport. The management UI is separate from the native media pipeline; single-application window streaming is not yet implemented.

Nexus | Multi-agent Engineering Workflows

A multi-agent collaboration layer for VS Code and GitHub Copilot. Modular plugins organize requirements analysis, specifications, task breakdown, implementation, code review, testing, and releases. Commands in Copilot Chat connect these stages into a workflow from requirements to delivery.

awesome-ai-roadmap | AI Knowledge Map

A Chinese-language knowledge base for AI engineering study and interview preparation, covering LLMs, multimodal AI, agents, RAG, MCP, orchestration frameworks, evaluation, and security governance. Organizes concepts, engineering trade-offs, and learning paths by topic, published as a searchable online wiki with MkDocs.

rustproxyparser | Cross-platform Proxy Resolution

A Rust library and CLI that reads environment variables and system proxy settings on macOS, Windows, and Linux, loads and executes PAC scripts, and returns normalized proxy results for a target URL. Supports deduplication, protocol filtering, and DIRECT fallback semantics.

ModernNovel | AI Novel-Writing Workspace

Built with TypeScript, React, and Cloudflare Workers. Combines chapter editing, character and world-building notes, a story canvas, writing skills, style memory, and a multi-model AI assistant in one workspace. Currently a proof of concept, with an online demo.

Super Polo | Personalized LLM Development

Explores local deployment and fine-tuning of open-source language models using personal conversations and public datasets. The goal is to learn an individual's phrasing, tone, and conversational style, with an emphasis on data privacy, local execution, and personalized dialogue.
