个人项目

以下是我在 GitHub 上维护的部分项目，涵盖远程桌面、跨平台基础库和 AI 应用。具体功能及开发进展以各仓库 README 为准。

NebulaDesk · 跨平台远程桌面

基于 Rust、Tauri 和 QUIC，面向 macOS、Windows、Linux 提供设备管理、访问授权和独立原生远程会话窗口，采用端到端加密传输。管理界面与原生音视频链路分离；单应用窗口串流尚未实现。

Nexus · 多智能体工程协作

面向 VS Code 与 GitHub Copilot 的多智能体协作层，通过模块化插件组织需求分析、规格设计、任务拆分、实现、代码审查、测试和发布工作。支持在 Copilot Chat 中使用命令，将需求到交付的多个环节串联起来。

awesome-ai-roadmap · AI 知识图谱

面向 AI 工程学习与面试准备的中文知识库，覆盖 LLM、多模态、Agent、RAG、MCP、框架编排、评测及安全治理。按主题组织概念、工程取舍和学习路径，通过 MkDocs 发布为可搜索的 在线 Wiki。

rustproxyparser · 跨平台代理解析库

使用 Rust 实现的代理解析库与命令行工具，读取环境变量及 macOS、Windows、Linux 系统代理配置，加载并执行 PAC 脚本，为目标 URL 返回规范化代理结果，支持代理去重、协议过滤和 DIRECT 回退语义。

ModernNovel · AI 小说创作工作台

使用 TypeScript、React 和 Cloudflare Workers 构建，将章节编辑、人物与世界观设定、故事画布、写作技巧、风格记忆和多模型 AI 助手整合到同一工作空间。当前处于 POC 阶段，提供在线体验。

Super Polo · 个性化大模型构建

探索在本地部署开源大模型，结合个人对话记录与公开数据进行微调，使模型学习特定的表达方式、语气与聊天风格，关注数据隐私、本地运行和个性化对话体验。
